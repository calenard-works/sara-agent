## Выделение текста (Emphasis)

**Жирный текст** (bold)

*Курсивный текст* (italic)

***Жирный и курсивный*** (bold + italic)

__Жирный подчёркнутый__ (underline bold)

_Курсивный подчёркнутый_ (underline italic)

~~Зачёркнутый текст~~ (strikethrough)

`inline code` (встроенный код)

## Текст внутри строки

Обычный текст с **жирным**, *курсивом*, `кодом` и ~~зачёркиванием~~ в одной строке.

## Списки (Lists)

### Нумерованный список

1. Первый элемент
2. Второй элемент
   1. Вложенный элемент 1
   2. Вложенный элемент 2
3. Третий элемент

### Маркированный список

- Элемент A
- Элемент B
  - Вложенный элемент B1
  - Вложенный элемент B2
- Элемент C

### Список с галочками (Task List)

- [x] Выполненная задача
- [ ] Невыполненная задача
- [x] Добавить тесты
- [ ] Задеплоить на продакшн

### Список с разными маркерами

* Звёздочка
+ Плюс
- Минус

## Код (Code)

### Встроенный код

Используйте `console.log()` для вывода в консоль.

Функция `calculateSum(a, b)` складывает два числа.

### Блок кода с указанием языка

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet("World"));
```

```python
def greet(name):
    return f"Hello, {name}!"

print(greet("World"))
```

```typescript
interface User {
  id: number;
  name: string;
}

const user: User = { id: 1, name: "Alice" };
```

```bash
#!/bin/bash
echo "Hello, World!"
```

```json
{
  "name": "sara",
  "version": "1.0.0",
  "scripts": {
    "build": "bun build",
    "test": "vitest"
  }
}
```

### Блок кода без языка

```
Это просто текст в блоке кода.
Никакой подсветки синтаксиса.
```

## Экранирование (Escaping)

Чтобы показать символы, используйте обратный слеш:

\* Это не курсив

\# Это не заголовок

\`Это не код`

\\ Это не экранирование
